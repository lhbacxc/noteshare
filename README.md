- ✅断点续传时做一次 md5 校验，确保文件是同一个文件，如果是同一个文件那就接着续传，因为有可能文件的位置或者是名称被移动或更改了。
    具体的方案现在如下
  - 在上传文件之前进行 MD5 校验，断点状态里保存 MD5 值，再次上传时优先进行 MD5 校验，如果 MD5 值相同，那就接着续传，否则重新上传。
  - 因为 R2/S3 中的 upload_id 是绑定 bucket + object key ，所以再上传文件时，如果 MD5 值相同，那就直接使用相同的 upload_id 进行续传。
