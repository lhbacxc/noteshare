# R2 文件级预签名 URL 管理功能设计文档

## 1. 变更背景

当前 GUI 工具已经支持生成预签名 URL，但仍存在以下不足：

- 只能统一设置一个全局过期秒数，无法按单个文件分别设置。
- 文件列表中无法直接看到每个文件最近一次预签名 URL 的到期信息或剩余时间。
- 选中单个文件时，底部结果区不能自动显示该文件当前仍有效的历史预签名 URL。

为提升日常使用效率，本次需要将预签名 URL 管理能力扩展到“文件级”。

## 2. 目标

本次变更目标如下：

- 支持为单个文件设置独立的默认预签名 URL 过期秒数。
- 支持在对象列表中显示该文件最近一次 URL 的到期时间与剩余时间。
- 支持在选中单个文件时，在底部显示该文件当前仍有效的历史预签名 URL。
- 支持将文件级默认时长与最近一次 URL 记录持久化保存到本地配置文件。

## 3. 非目标

本次不实现以下能力：

- 不将预签名 URL 或到期记录同步写回 R2 元数据。
- 不支持同一个文件保留多条历史 URL 记录，仅保留最近一次生成记录。
- 不支持多个用户共享本地 URL 记录。
- 不实现自动后台轮询刷新 URL，仅在 GUI 操作与界面刷新时计算状态。

## 4. 设计原则

- 本地持久化优先，保证工具重启后仍可看到文件级配置与最近一次 URL 状态。
- 尽量复用现有 GUI 结构，不引入新的复杂窗口。
- 对已过期 URL 统一视为无效，不在底部展示。
- 列表状态展示以“最近一次生成的 URL 记录”为准。

## 5. 配置结构扩展

在现有 `config.json` 中新增 `object_url_settings` 字段，用于按 `bucket + object key` 维度保存文件级状态。

示例结构：

```json
{
  "object_url_settings": {
    "notelink": {
      "folder/demo.pdf": {
        "default_expire_seconds": 1800,
        "last_presigned_url": "https://...",
        "last_generated_at": "2026-05-24T16:30:00+08:00",
        "last_expires_at": "2026-05-24T17:00:00+08:00"
      }
    }
  }
}
```

说明：

- 第一层 key 为 bucket 名称。
- 第二层 key 为对象完整 key。
- `default_expire_seconds` 表示该文件默认的签名时长。
- `last_presigned_url` 表示最近一次生成的 URL。
- `last_generated_at` 表示最近一次生成时间。
- `last_expires_at` 表示最近一次 URL 的到期时间。

## 6. 界面改造

### 6.1 顶部配置区

保留当前的统一过期秒数字段，但语义调整为：

- 作为“文件默认过期秒数的快捷输入值”
- 作为未单独设置文件时的默认回退值

该值不再表示所有文件统一共用一个有效期。

### 6.2 对象列表区

新增列：

- `默认过期秒数`
- `URL 到期 / 剩余时间`

展示规则：

- `默认过期秒数` 显示该文件的文件级时长；若未单独设置，则显示全局默认值。
- `URL 到期 / 剩余时间` 显示最近一次生成记录：
  - 若从未生成过 URL，则显示为空。
  - 若已过期，则显示“已过期”以及到期时间。
  - 若仍有效，则显示“到期时间 | 剩余时间”。

### 6.3 底部结果区

选中单个文件时：

- 若存在未过期的历史 URL，则底部 URL 输入框直接显示该 URL。
- 若历史 URL 已过期，则底部显示为空。
- 若从未生成过 URL，则底部显示为空。

选中多个文件时：

- 底部 URL 输入框显示为空。

### 6.4 新增操作按钮

新增按钮：

- `设置选中文件过期秒数`

行为：

- 仅允许单选文件时使用。
- 弹出输入框填写过期秒数。
- 保存后更新本地配置与列表显示。

## 7. 交互规则

### 7.1 设置单文件默认过期秒数

1. 用户在列表中选中单个文件。
2. 点击“设置选中文件过期秒数”。
3. 输入一个大于 0 的整数。
4. 工具将该值保存到对应文件记录中。
5. 刷新当前列表显示。

### 7.2 生成预签名 URL

1. 用户在列表中选中单个文件。
2. 点击“生成预签名 URL”。
3. 工具读取该文件的默认过期秒数：
   - 若该文件单独设置过，则用文件级值。
   - 否则使用顶部统一默认值。
4. 调用 R2 生成 URL。
5. 保存最近一次 URL、生成时间和到期时间。
6. 更新底部 URL 输入框与列表状态列。

### 7.3 选择文件时的底部 URL 联动

1. 用户切换列表选中项。
2. 若当前为单选：
   - 读取该文件的最近一次 URL 记录。
   - 若记录不存在，显示为空。
   - 若已过期，显示为空。
   - 若仍有效，显示历史 URL。
3. 若当前为多选或未选中，显示为空。

## 8. 数据处理逻辑

### 8.1 文件状态合并

刷新对象列表时，需要把 R2 返回的对象信息与本地 `object_url_settings` 合并，形成 GUI 展示对象：

- R2 对象原始字段：
  - `key`
  - `size`
  - `last_modified`
  - `storage_class`
- 本地扩展字段：
  - `default_expire_seconds`
  - `last_presigned_url`
  - `last_generated_at`
  - `last_expires_at`
  - `remaining_display`

### 8.2 已过期判断

判断规则：

- 若 `last_expires_at` 为空，则视为无有效 URL。
- 若当前时间大于等于 `last_expires_at`，则视为已过期。
- 已过期时：
  - 底部 URL 不显示
  - 列表列显示“已过期”

## 9. 程序结构改动

### `config_manager.py`

需要扩展：

- 默认配置增加 `object_url_settings`
- 读取配置时清洗该字段结构
- 提供对象级记录的读取与保存辅助逻辑

### `gui.py`

需要扩展：

- 新增对象列表列
- 新增“设置选中文件过期秒数”按钮
- 监听列表选中事件
- 生成 URL 后保存文件级状态
- 选中单个文件时动态刷新底部 URL

### `r2_client.py`

无需改变 R2 API 调用方式，但 GUI 层在生成 URL 后需要额外计算并保存：

- 生成时间
- 到期时间

## 10. 异常处理

需要覆盖以下场景：

- 未选中文件时尝试设置过期秒数
- 多选时尝试设置单文件过期秒数
- 输入无效的过期秒数
- 文件记录不存在时的回退显示
- 历史 URL 已过期时的空显示逻辑

## 11. 测试范围

本次至少验证以下内容：

- 单文件默认过期秒数可设置并持久化
- 未设置文件可回退到统一默认值
- 生成 URL 后本地记录会更新
- 列表可显示到期时间与剩余时间
- URL 过期后列表显示已过期
- 选中单个文件时仅在 URL 仍有效时显示到底部
- 关闭后重新打开 GUI，文件级配置与历史 URL 状态仍可恢复
