# R2 容量圆环显示修正设计

## 1. 背景

当前右侧容量侧栏已经支持展示当前 bucket 的容量圆环和已用比例，但在实际使用中存在两个显示问题：

- 圆环视觉上接近整圈着色，不符合“未使用部分为底环，已使用部分为前景弧线”的表达预期
- 对于极小占用比例，例如 `3.93 MB / 10 GB`，文案会显示为 `0.0%`，容易误导用户以为完全没有占用

本次改动目标是修正显示层逻辑，不调整容量统计口径。

## 2. 本次目标

- 圆环底环始终保持浅色
- 只有已用比例对应的前景弧线显示为强调色
- `0 < percent < 0.1` 时文案显示为 `<0.1%`
- `0` 时仍显示 `0.0%`
- 不改变当前 bucket 容量统计和刷新逻辑

## 3. 非目标

- 本次不调整右侧容量栏布局
- 本次不修改 bucket 容量统计来源
- 本次不为极小占用比例增加“最小可见着色段”
- 本次不重做配色体系

## 4. 显示规则

### 4.1 百分比文案

- `used_bytes = 0` 时：显示 `0.0%`
- `0 < percent < 0.1` 时：显示 `<0.1%`
- `0.1% <= percent < 100%` 时：显示正常百分比，例如 `34.8%`
- `percent >= 100%` 时：显示真实百分比，例如 `123.4%`

### 4.2 圆环绘制

- 先绘制浅色底环，表示总容量
- 再根据真实占用比例绘制前景弧线
- 当前景比例为 `0` 时，不绘制前景弧线
- 当前景比例大于 `0` 且小于 `100%` 时，严格按真实比例绘制
- 当前景比例超过 `100%` 时，前景弧线绘制为满环

## 5. 代码调整范围

主要改动集中在 `gui.py`：

- 调整 `_refresh_storage_summary()` 中的比例文案格式化
- 新增独立的容量百分比格式化方法
- 调整 `_draw_storage_ring()` 的前景弧线绘制逻辑

本次不修改以下逻辑：

- `prefix` 下获取全量对象列表做容量统计
- 上传、删除后的本地即时容量更新
- 刷新失败时保留上一次成功容量状态

## 6. 验证范围

- `0 B / 10 GB` 时显示 `0.0%`，且只有底环
- `3.93 MB / 10 GB` 时显示 `<0.1%`
- 极小占用比例时，圆环不会再看起来像整圈都着色
- 接近 `100%` 和超过 `100%` 时显示仍然正确
- 不影响右侧侧栏布局和现有容量刷新逻辑
